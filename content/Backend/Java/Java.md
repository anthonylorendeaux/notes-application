## Introduction

Java est un langage de programmation populaire, orienté objet et plateforme-indépendante. Il est utilisé pour créer une grande variété d'applications, des applications web aux applications mobiles en passant par les logiciels embarqués. Java est appré pour sa robustesse, sa sécurité et sa large communauté de développeurs. Il peut être verbeux et moins performant que certains langages, mais il reste un choix puissant et polyvalent pour les développeurs.

## Caractéristiques Clés

### Indépendance de la Plateforme

- **WORA (Write Once, Run Anywhere)** : Les programmes Java sont compilés en bytecode qui peut être exécuté sur n'importe quelle machine équipée d'une machine virtuelle Java (JVM), indépendamment de l'architecture matérielle sous-jacente.

### Orienté Objet

- **Encapsulation, Héritage, Polymorphisme** : Java suit les principes de la programmation orientée objet (POO), ce qui permet de créer des applications modulaires et de réutiliser du code.

### Simple et Sécurisé

- **Syntaxe Simple** : Inspiré de C++ mais sans les complexités comme les pointeurs et la gestion manuelle de la mémoire.
- **Sécurité** : Comprend un gestionnaire de sécurité pour définir des règles sur l'exécution de classes spécifiques et un modèle de sécurité rigoureux pour protéger contre les virus et autres menaces.

### Robuste et Portable

- **Gestion Automatique de la Mémoire** : Utilisation du ramasse-miettes (Garbage Collector) pour gérer la mémoire et réduire les erreurs de gestion de mémoire.
- **API Riche** : Fournit une bibliothèque standard riche (Java API) qui offre des outils pour tout, des structures de données aux communications réseau.

## Historique

### Développé par Sun Microsystems en 1995

- **Origines** : Java a été inicié par James Gosling, Mike Sheridan et Patrick Naughton dans le projet "Green" chez Sun Microsystems. Initialement conçu pour les appareils électroniques grand public, il a évolué pour devenir un langage de programmation généraliste.
- **Lancement** : La première version publique de Java (Java 1.0) a été publiée en 1995 avec la promesse "Write Once, Run Anywhere", révolutionnant le développement logiciel à l'époque.

### Acquis par Oracle Corporation en 2010

- **Transition** : En 2009, Oracle a annoncé l'acquisition de Sun Microsystems, qui a été finalisée en janvier 2010. Avec cette acquisition, Oracle est devenu le principal mainteneur de Java.
- **Évolution** : Sous Oracle, Java a continué à évoluer avec des versions majeures régulières, introduisant de nouvelles fonctionnalités et améliorations de performance. Les versions récentes comme Java 8, 11 et au-delà ont apporté des innovations significatives telles que les lambdas, les streams, et les améliorations de la gestion de la mémoire.
